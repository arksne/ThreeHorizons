# backups — снимки проекта

Здесь лежат zip-архивы `docs/` + `src/` перед рискованными изменениями и в конце каждой фазы:
`backups/v0.N_<YYYY-MM-DD>/`.

## Правила

- Папка в `.gitignore` — в репозиторий не попадает.
- Бэкап перед: сменой лора, миграцией профиля, массовым экспортом, релизом фазы.
- Имя фиксирует версию; CHANGELOG ссылается на бэкап.

Скрипт: `tools/backup.ps1` (**Ф0.9**).
