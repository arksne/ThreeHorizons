# tests — офлайн-тесты

Тесты Luau-модулей без Roblox Studio: запускаются через `luau` CLI, результат — `PASS=x FAIL=y`,
код возврата ≠ 0 при провале.

## Правила

- Один модуль — минимум один тест; тест лежит рядом по смыслу, а не «где вышло».
- Тестируем только чистую логику (данные, экономика, генераторы, облачное поле) — не рендер.
- Каждый найденный баг закрывается тестом, который его ловит.

Запуск: `pwsh -File tools/test.ps1` (появится в Ф5.10).
Гейт: `docs/QUALITY_ASSURANCE.md` S-1.
