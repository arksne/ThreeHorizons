# SECURITY SPEC (APPROVED v0.1)
1. Сервер — единственный авторитет: деньги, грузы, владение, награды, урон. Клиентские значения игнорируются.
2. Все RemoteEvents валидируются в Validators.lua: тип, диапазон, владение, кулдаун, дистанция до объекта (<40 st для взаимодействия).
3. Идемпотентность: каждая награда/покупка с `txId`; повтор с тем же txId — no-op.
4. RateLimit: таблица лимитов/с, бан по нарастающей (предупреждение → кик). Журнал: Audit.lua пишет все стратегические перемещения (топливо/кристалл/зерно свыше порога).
5. Текст: только TextService:FilterStringAsync перед показом другим игрокам; имена гильдий/кораблей — премодерация фильтром.
6. DataStore: UpdateAsync-транзакции, никаких прямых Set из клиента; BindToClose досохранение.
7. Логи: security.log (кто/что/когда), ротация; PII минимум.
8. Эксплойт-классы закрыты: дублирование (txId), подмена цен (прайс только серверный Goods.lua), повтор наград (флаг quests{}), спам Remotes (лимиты).

# PLATFORM SUPPORT (APPROVED v0.1)
- Windows/macOS: полный профиль, TargetRadius 1200 st, тени вкл.
- Mobile/планшет: TargetRadius 500 st, тени выкл, LOD−1, кнопки ≥44pt, штурвал — виртуальный джойстик, торговля — крупные строки.
- Управление едино (UX_DESIGN_SPEC): E — взаимодействовать, F — швартовка/якорь, M — карта; на тач — те же действия кнопками.
- Графпрофили: Low/Med/High, авто по FPS (<30 → понижение).

# BALANCING (v0.1 PROPOSED — числа после тестов)
Стартовые цены (предложение): лёгкий корпус 800, средний 3000, тяжёлый 9000; обслуживание 2%/рейс; доход мастерской ~40/игрочас; профессии: качание 1–5 ч простые, 20+ ч сложные. Риски: шторм ×1.5 износ, пираты — потеря до 30% груза. Аналитика серверная, приватная (агрегаты, без PII).

# ANIMATION / CAMERA (APPROVED v0.1)
Анимации: ходьба/бег/работа/экипаж — сдержанные, без акробатики; механизмы — loop 1–2 с. Камера: исследование (3-е лицо, 8–12 м), город (5–8 м), корабль (орбита 15–30 м + вид от штурвала), интерьер (первое/близкое 3-е). Катсцены скипабельны, не блокируют управление дольше 5 с.
