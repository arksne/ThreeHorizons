# CONTRADICTIONS & DECISIONS LOG
> Все конфликты между Master Prompt, 9 атласами и доп. требованиями. Формат: ID · место · решение · статус.

## C-01. Площади островов на артах (108 / 432 / 475 км²)
- Конфликт: арты дают точные площади, совпадающие с прямоугольниками 12×9 / 24×18 / 25×19.
- Решение: считать 12×9 и т.д. **проектными ориентирами лора**, 108/432/475 — их арифметикой. Игровые размеры — только из `WORLD_MASTER_MAP.md` (сжатая шкала).
- Статус: APPROVED.

## C-02. Морвей vs Морвей/Моряк (Leonard Morvey)
- Конфликт: текст — Леонард Морвей; атласы — Морвей / Моряк / Морвей.
- Решение: канон — **Морвей / Morwey** (Леонард и Леона Морвей). Остальное — ошибки генерации артов.
- Статус: APPROVED.

## C-03. Специализации Гринвальда: «фермер» vs «арбалетчик»
- Конфликт: Master Prompt — следопыт/лучник/пехотинец/арбалетчик; атлас Гринвальда — следопыт/лучник/пехотинец/фермер.
- Решение: боевой набор из Master Prompt — APPROVED; «фермер» — не специализация, а профессия (земледелие/животноводство, раздел 7 Bible). В UI показывать раздельно.
- Статус: APPROVED.

## C-04. Возраст Элианы Вейл (24 vs без возраста)
- Конфликт: часть атласов без возраста женских версий.
- Решение: зеркальный возраст — Элиана 24, Леона 26, Грейс 23.
- Статус: APPROVED.

## C-05. Размер/высота Эстерхольма и Гавани
- Конфликт: 1.5 км² везде ок; высота Гавани 1700 м стабильна; размеры Гавани 0.8×0.6 vs 0.48 км².
- Решение: Эстерхольм 1.5×1 км / 1900 м / ~15 000; Гавань 0.8×0.6 км / 1700 м / ~8 000.
- Статус: APPROVED.

## C-06. Дирижабли/аэростаты на артах vs «корабли с двигателями» в тексте
- Конфликт: арты показывают баллоны и винты; текст — парус + двигатель + эфирное топливо.
- Решение: отдельного класса «дирижабль» нет. Баллоны на артах = художественная подача эфирной подъёмной системы кораблей. Лор не меняется, механика едина (топливо/двигатель/паруса).
- Статус: APPROVED (возможен PROPOSED визуальный кит «аэростат-обвес» позже).

## C-07. Масштаб столиц (2.5–3 км) vs острова (12–25 км)
- Конфликт: столица 3×2.5 км занимает ~1/8 острова — правдоподобно для лора, но не для Roblox (см. карту сжатия).
- Решение: лор-размеры — APPROVED как «истинный мир»; игровые — сжатые представители в `WORLD_MASTER_MAP.md`, с явным коэффициентом.
- Статус: APPROVED.

## C-08. «Древние руины» на атласе vs «без древнего зла»
- Конфликт: атлас показывает «Древние руины» как локацию; текст запрещает сюжет про древнее зло.
- Решение: руины как **заброшенные поселения/обломки** (нейтральные POI для лута и исследований), без мистики. Переименовать в реестре в «Заброшенные поселения».
- Статус: APPROVED.

## C-09. Ткани в ресурсах атласа vs textile-цепочка текста
- Конфликт: нет — дополняют друг друга. Зафиксировать цепочку волокно→ткань→одежда как APPROVED.
- Статус: APPROVED.
