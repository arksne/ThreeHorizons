# VISUAL DESIGN BIBLE (APPROVED v0.1)
> Источник: 9 атласов ref01–ref09. Арт — референс; при конфликте с текстом приоритет тексту (D-001).

## 1. Что взято из атласов (канон)
- Три острова над облаками + Эстерхольм-хаб + Чёрная Гавань; столицы Аркенхольд / Вальмара / Гринхольм.
- 6 героев с парными М/Ж версиями: Вейл (красно-коричневая кожа, инженерия), Морвей (синий камзол, торговля), Эшфорд (зелёный плащ, следопыт).
- Корабли: парус + корпус + эфирный двигатель (баллоны на артах = худ. подача подъёмной силы, C-06).
- Интерьеры: тёмное дерево, латунь, тёплый свет; UI: пергамент + латунь + тонкие рамки, круглая мини-карта.
- Районы столиц и поселения из атласов — зафиксированы в Bible §2.
- Палитры сняты в DESIGN_TOKENS.md (Арквейн графит/медь/бордо; Вальмер известняк/бирюза/мope; Гринвальд олива/терракота/солома).

## 2. Что отброшено как ошибки генерации
- Разночтения фамилий (Морвей/Моряк → Морвей), «фермер» как специализация, площади Гавани 0.48 → 0.8×0.6 км, «древние руины» с мистикой → заброшки без магии.
- Масштабные цифры на рамках (1:500 000 и т.п.) — декоративные, не канон.

## 3. Арт-контроль (обязателен)
Каждый ассет: масштаб по MASTER_SCALE_SPEC, токены из DESIGN_TOKENS, имя TH_*, статус concept/blockout/final/lod, запись в ASSET_REGISTRY. Проверка — gate A-1 (QUALITY в SPECS_COMBINED). Концепт ≠ модель: рендер без LOD/коллизий моделью не считается.
