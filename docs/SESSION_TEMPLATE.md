# SESSION_TEMPLATE — шаблон рабочей сессии

> Заполняется за 2 минуты. Цель: следующая сессия (или другой агент) продолжает без «а что тут было».

## Перед началом

- [ ] Прочитать `docs/STATUS.md` — где мы.
- [ ] Открыть шаг в `docs/roadmap/phase-XX-*.md` и прочитать его целиком (включая «Готово, когда»).
- [ ] Проверить канон, на который шаг ссылается (`docs/...`), — не по памяти.
- [ ] `git status` — рабочее дерево чистое; иначе сначала разобрать.
- [ ] `pwsh -File tools/preflight.ps1` — база зелёная.

## Во время работы

- Один шаг = один коммит с номером: `Ф4.2: базовый дом Арквейна`.
- Проверять по критерию «Готово, когда», а не «вроде работает»: команда / цифра / скриншот / тест.
- Наткнулись на противоречие в доках — стоп, запись в `docs/DECISIONS.md`, потом код.

## После шага

- [ ] Отметить статус: `python -X utf8 tools/make_progress.py <номер> done`.
- [ ] Пересобрать канвасы: `python -X utf8 tools/make_roadmap_canvas.py`.
- [ ] Коммит + (если конец фазы) тег и бэкап `pwsh -File tools/backup.ps1`.
- [ ] Обновить `docs/STATUS.md` (строка шага + «дальше»).
- [ ] Если меняли правило мира — запись в `DECISIONS.md` и `CHANGELOG.md`.

## Конец сессии

Записать в `docs/STATUS.md` блок «Последняя сессия»:
```
### <дата>
- Сделано: <шаги + evidence>
- Не сделано / блокеры: <...>
- Дальше: <следующий шаг>
```
