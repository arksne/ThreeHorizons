# Ф6 · Текстурная библиотека (23 материала)

> **Цель:** Все 23 материала канона с полным набором карт (albedo/normal/roughness), бесшовные и строго в палитре DESIGN_TOKENS. Сейчас в плане 3 материала — остальные 20 нечем красить.
> **Зависит от:** Ф4 (визуальная библиотека), Ф5 (арт-пайплайн) · **Выход:** 69 PNG (23×3) + `blender/textures/manifest.json` с HEX и тайлингом · **Сессий:** 3
> **Канон:** `DESIGN_TOKENS.md`, `TEXTURE_PIPELINE.md`, `world/WORLD_PALETTE.md`

## Правила фазы

- Материал = **3 карты**: albedo, normal, roughness. Нормали — из высоты, tangent-space.
- Бесшовность обязательна: проверка тайлингом 3×3, шов не виден.
- HEX — **только** из `DESIGN_TOKENS.md`. Ни одного «похожего» цвета.
- Размер 1024² (по `constants.json → art.textureSize`), тайлинг 4 м.

## Шаги

### 6.1 · Реестр материалов
- **Действие:** `blender/textures/manifest.json`: 23 материала × (albedo/normal/roughness), HEX из палитры, тайлинг 4 м, назначение (стена/пол/дерево/металл/…).
- **Готово, когда:** В манифесте **23 материала**, у каждого 3 карты и HEX; каждый HEX совпадает с `DESIGN_TOKENS.md` (проверка скриптом, 0 расхождений).

### 6.2 · Генератор `tools/gen_textures.py`
- **Действие:** numpy+Pillow: value-noise + FBM + кластеры (кладка, доска, камень, черепица, солома, ткань). Нормаль из карты высот (Sobel). Roughness — из материала (камень шероховатый, металл гладкий).
- **Готово, когда:** `python -X utf8 tools/gen_textures.py --all` → 69 PNG; время прогона < 60 с; у каждого PNG правильный размер 1024² и 4 канала (RGB/RGBA + grayscale для карт).

### 6.3 · Бесшовность
- **Действие:** Проверка тайлингом 3×3: края должны совпадать. Алгоритм — периодический value-noise, поэтому шов невозможен по построению; проверяем визуально.
- **Готово, когда:** Контактный лист тайлинга 3×3 для всех 23 материалов в `ART_ASSETS/textures/tiling/`; на листах нет видимых швов (визуальная приёмка).

### 6.4 · Материалы Арквейна (7)
- **Действие:** GRAPHITE, STONE, WOOD_DARK, BURGUNDY, COPPER, STEEL, PLASTER — графит, камень, тёмное дерево, бургундия, медь, сталь, штукатурка.
- **Готово, когда:** 7 материалов × 3 карты = 21 PNG; визуально: камень ≠ сталь по roughness (камень ≥ 0.7, сталь ≤ 0.35 — проверяется по манифесту).

### 6.5 · Материалы Вальмера (7)
- **Действие:** LIMESTONE, CREAM, SAND, TEAL, SEA, BRONZE, WHITE — известняк, крем, песок, бирюза, море, бронза, белила.
- **Готово, когда:** 7 × 3 = 21 PNG; бронза и известняк различимы по roughness и цвету; все HEX из палитры Вальмера.

### 6.6 · Материалы Гринвальда (7)
- **Действие:** OLIVE, FOREST, WOOD, BEIGE, STRAW, TERRA, STONE — олива, лес, дерево, беж, солома, терра, камень.
- **Готово, когда:** 7 × 3 = 21 PNG; солома и дерево различимы по рисунку (солома — вертикальные полосы, дерево — волокна).

### 6.7 · Нейтральные и общие (2)
- **Действие:** Материалы вне фракций: парусина (паруса, Canvas) и металл корабля. Общие для всех островов.
- **Готово, когда:** 2 × 3 = 6 PNG; парусина — с полотняным плетением (видно в roughness); итого **69 PNG = 23 × 3** (сходится с реестром).

### 6.8 · Тайлинг и приёмка
- **Действие:** Проверка тайлинга на реальном размере: 4 м на модель Арквейна 8×10 м (из `Buildings.json`), без «растянутых» текстур. Фиксация: тег `v0.5.0`.
- **Готово, когда:** Тайлинг-лист 4 м наложен на рендер дома — масштаб читается; все 69 PNG в `ART_ASSETS/textures/`; манифест обновлён; тег `v0.5.0`; бэкап.

## Definition of Done фазы

- [ ] 69 PNG (23 материала × 3 карты), размер 1024².
- [ ] Бесшовность проверена тайлингом 3×3 для всех 23.
- [ ] Все HEX из DESIGN_TOKENS, расхождений 0.
- [ ] Тайлинг 4 м, приёмка на доме 8×10 м.
- [ ] Тег `v0.5.0`.

## Риски и грабли

- **Текстуры без развёртки UV** — половина работы впустую: UV-раскладка проверяется в Ф5.
- **Цвет «похожий на палитру»** — не берём: только точное совпадение HEX.
- **Нормали из RGB** — только из карты высот, иначе свет ломается.

## Чего в этой фазе НЕ делаем

- Не делаем текстуры лута/декора — это Ф7 (ассеты).
- Не делаем PBR-спеки/металли/шероховатость по слоям — ограничение Roblox (3 материала на ассет).
- Не генерируем текстуры персонажей — отдельный пайплайн.
