# Ф11 · QA, оптимизация, закрытая альфа

> **Цель:** доказать цифрами, что v0.1 играбельна: гейты закрыты, бюджеты соблюдены, сохранения
> не теряются, сервер держит нагрузку. Затем — закрытая альфа 50–100 игроков.
> **Зависит от:** Ф10 · **Выход:** чек-лист R-1 с evidence + релиз-тег `v1.0.0-alpha` · **Сессий:** 2–3
> **Канон:** `QUALITY_ASSURANCE.md`, `SPECS_COMBINED.md` (PLATFORM/LIVE OPS), `RELEASE_CHECKLIST_ALPHA.md`,
> `ARCHITECTURE.md` §5

## Правила фазы

- «Работает» = есть evidence: команда, скриншот, цифра из Output. Без evidence пункт не закрыт.
- Сначала цифры, потом косметика: FPS/parts/Remote важнее последнего декора.
- Любой найденный баг: воспроизведение → фикс → тест, который его ловит.

## Шаги

### 11.1 · Чек-лист R-1
- **Действие:** пройти `RELEASE_CHECKLIST_ALPHA.md` и адаптировать под v0.1: импорт/сборка, тесты
  (S-1), бюджеты частей, сквозной цикл, откат, бэкап. Каждый пункт — с evidence.
- **Готово, когда:** все пункты отмечены, у каждого ссылка на артефакт (лог/скрин/цифра).

### 11.2 · Производительность
- **Действие:** замеры: near-чанк parts ≤ 8 000, FPS ПК ≥ 60 / мобилка ≥ 30, Remote ≤ 60/с,
  память, draw calls (если доступно); профили Low/Med/High + авто-понижение при FPS < 30.
- **Готово, когда:** таблица «устройство → профиль → FPS → parts» заполнена; узкие места названы.

### 11.3 · Сетевые и анти-дюп тесты
- **Действие:** сценарии: 2 клиента, rejoin ×3, разрыв соединения во время сделки, повтор `txId`,
  спам Remote 100/с, попытка клиентской подмены цены.
- **Готово, когда:** ни один сценарий не даёт дубля денег/предметов; журнал аудита фиксирует.

### 11.4 · Стресс-тест
- **Действие:** 10 клиентов (или эмуляция ввода) в одном районе: NPC, толпа, облака, корабль;
  замер FPS сервера/клиента, Remote, ошибки.
- **Готово, когда:** деградация плавная, нет ошибок DataStore/Remote; лимит шарда подтверждён (60).

### 11.5 · Анимация и камера
- **Действие:** базовые анимации (ходьба/бег/работа) из доступных licensed-анимаций; камера в
  интерьере (первое/близкое третье), на корабле (Ф8.7) — финальная настройка.
- **Готово, когда:** нет «скольжения» персонажа, камера не проходит сквозь стены (raycast).

### 11.6 · Тексты и безопасность общения
- **Действие:** фильтр `TextService:FilterStringAsync` для имён кораблей/гильдий и чата; проверка
  имён по правилам; логи.
- **Готово, когда:** нефильтрованное имя нельзя сохранить; чат фильтруется.
- **Канон:** `SPECS_COMBINED.md` §SECURITY 5.

### 11.7 · Релиз-сборка
- **Действие:** `rojo build` релизной версии, версия в `version.json`, миграции профиля, тег git,
  бэкап `backups/v1.0_<дата>`, инструкция запуска.
- **Готово, когда:** сборка открывается с нуля, профиль старой версии мигрирует без потерь.

### 11.8 · Закрытая альфа 50–100
- **Действие:** инвайты, окно теста 3–7 дней, метрики: удержание, квесты, крафты, FPS, ошибки,
  отзывы; отдельная форма/канал для багов.
- **Готово, когда:** ≥ 50 участников или ≥ 100 часов сессий; топ-10 проблем собраны.

### 11.9 · Мониторинг и откат
- **Действие:** дашборд (FPS, Remote/с, ошибки DataStore, краши), процедура отката: снапшот DataStore
  + предыдущий тег; прогон отката на тестовом шарде.
- **Готово, когда:** откат выполнен по инструкции и проверен; никто не потерял прогресс.

### 11.10 · Долги и следующий этап
- **Действие:** backlog v0.2: вторая фракция, интерьеры, бой/абордаж, флот, кросс-шард, локализация;
  приоритизация по влиянию на удержание.
- **Готово, когда:** backlog с приоритетами и оценками записан в `ROADMAP_0.2.md` (будет создан).

### 11.11 · Фиксация v0.1
- **Действие:** `STATUS.md` — итог, `CHANGELOG.md` — v1.0.0-alpha, DECISIONS — «v0.1 закрыта»,
  тег `v1.0.0-alpha`, бэкап.
- **Готово, когда:** любой новый участник собирает и запускает игру по документам.

## Definition of Done фазы

- [ ] R-1 чек-лист с evidence (не «вроде работает»).
- [ ] Таблица производительности по профилям, бюджеты соблюдены.
- [ ] Анти-дюп и стресс пройдены.
- [ ] Релиз-сборка + миграции + бэкап + тег.
- [ ] Закрытая альфа проведена, топ-10 проблем и backlog v0.2 готовы.
- [ ] Откат проверен.

## Риски и грабли

- **«Потом отполируем»** — оптимизация после альфы стоит втрое; бюджет держать с Ф6.
- **Миграции без теста** — старая версия профиля ломает игрока; тестировать на копии данных.
- **Альфа без метрик** — не понять, что чинить; метрики до инвайтов.
- **Откат «на словах»** — прогон отката до релиза, не после.

## Чего в этой фазе НЕ делаем

- Публичного релиза, монетизации, Steam-сборки.
- Новых фич: только стабилизация и то, что критично для удержания.
