# Ф14 · Звуковая библиотека (полный набор)

> **Цель:** Полный набор звуков по зонам (порт, рынок, мастерская, таверна, море, лес, каюта), погодные слои и 3 музыкальные темы. Ф13 делает 12–15 SFX на срез v0.1 — на полный мир нужен свой системный обход.
> **Зависит от:** Ф13 (UI и звук v0.1) · **Выход:** `blender/sounds/manifest.json` + ~50 звуков + 3 музыкальные темы · **Сессий:** 3
> **Канон:** `AUDIO_DESIGN_BIBLE.md`, `AUDIO_UX_OPTIMIZATION.md`, `constants.json → audio`

## Правила фазы

- Источник — **только original/licensed**: в манифесте у каждого трека — лицензия и источник.
- Нормализация ≤ **−12 dBFS** (`constants.json → audio.uiMaxDb`); пики измеряются, не оцениваются.
- 3D-источник — только у важных объектов; **лимит одновременных** источников (нет «стены шума»).
- Зоны переключаются **кроссфейдом 2–3 с** — без щелчка.

## Шаги

### 14.1 · Реестр звуков
- **Действие:** `blender/sounds/manifest.json`: звук → зона → источник → лицензия → лимит источников → громкость. Зоны: порт, рынок, мастерская, таверна, море, лес, каюта, погода.
- **Готово, когда:** В манифесте ≥ 50 звуков по 8 зонам; у каждого — зона, источник, лицензия, громкость; все лицензии — original/licensed (проверка: поле `license` заполнено у всех).

### 14.2 · Звуки порта и рынка
- **Действие:** Гудение порта, скрип снастей, удары молота, голоса торговцев, скрип тележки, колокол. Отдельно — «толпа» (слой для численности).
- **Готово, когда:** ≥ 8 звуков в группе `port`/`market`; каждый с измеренным пиком ≤ −12 dBFS; в сумме на зону ≤ 4 одновременных источника (проверяется в Play).

### 14.3 · Звуки мастерской и таверны
- **Действие:** Стук молота, шипение горна, жар в горне, музыканты, смех, звон кружек, скрип половицы.
- **Готово, когда:** ≥ 8 звуков в группах `workshop`/`tavern`; горн слышно громче фоновых звуков (измерение относительной громкости в манифесте).

### 14.4 · Звуки моря и леса
- **Действие:** Волны, ветер, скрип корпуса, чайки, плеск; шорох листвы, птицы, журчание, треск костра.
- **Готово, когда:** ≥ 8 звуков в группах `sea`/`forest`; звуки моря зациклены бесшовно (проверка: стык петли не слышен).

### 14.5 · Звуки кают и помещений
- **Действие:** Скрип переборок, шаги по дереву, стук двигателя (55 Гц + шум, low-pass), гудение приборов, скрип руля.
- **Готово, когда:** ≥ 6 звуков в группе `cabin`; звук двигателя = 55 Гц + шум с low-pass (проверяется спектрограммой в `ART_ASSETS/sounds/spectrum/`).

### 14.6 · Погодные слои
- **Действие:** 4 состояния погоды: ясно, облачно, туман, шторм. Ветер и дождь должны накладываться на зонный звук, а не заменять его.
- **Готово, когда:** 4 погодных слоя в манифесте; при смене погоды громкость зонного звука падает, погодного растёт (проверка по Output: сумма не выше −12 dBFS).

### 14.7 · Музыкальные темы
- **Действие:** 3 темы: Арквейн (технологии), порт (торговля/общение), море (свободное плавание). 70–95 BPM, струнные+духовые, кроссфейд по зоне 2–3 с.
- **Готово, когда:** 3 трека в манифесте с BPM в диапазоне 70–95 (проверяется тегом в имени файла); переход между зонами без щелчка (прослушка в Play, запись в `STATUS.md`).

### 14.8 · Звуковой дизайн и приёмка
- **Действие:** Прослушка по зонам: нет «стены шума», громкость выравнена, 3D-только у важного. Фиксация: тег `v0.14.0`.
- **Готово, когда:** Прослушка по 8 зонам записана в `STATUS.md` (громкость, лимит источников, дефекты); тег `v0.14.0`; бэкап.

## Definition of Done фазы

- [ ] `manifest.json`: ≥ 50 звуков по 8 зонам + 4 погодных слоя + 3 темы.
- [ ] Пики всех треков ≤ −12 dBFS (измерено).
- [ ] Лимит одновременных источников соблюдён во всех зонах.
- [ ] Кроссфейд 2–3 с без щелчка.
- [ ] Тег `v0.14.0`.

## Риски и грабли

- **«Стена шума»** — источник на источник: лимит источников обязателен.
- **Щелчок на кроссфейде** — только плавные переходы, не переключение.
- **Пики выше −12 dBFS** — измерять, а не «на глаз».

## Чего в этой фазе НЕ делаем

- Не делаем озвучку персонажей и реплики.
- Не делаем локализованные звуки (Ф16 — только текст).
- Не делаем звуки для второй/третьей фракции (Ф20).
