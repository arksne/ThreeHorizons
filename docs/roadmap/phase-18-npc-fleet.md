# Ф18 · Флот NPC и офлайн-симуляция

> **Цель:** Мир не должен быть пустым между игроками: NPC-капитаны возят грузы по маршрутам, сервер считает их офлайн тиками (5 мин, кап 24 ч) вместо вечной физики каждого. Плюс общие события: одно пиратское нападение — одно на всех рядом, без копий (Bible §7).
> **Зависит от:** Ф10 (корабли), Ф16 (механики) · **Выход:** NPC-флот с офлайн-симуляцией + общие события для всех рядом · **Сессий:** 3
> **Канон:** Bible §4 (флот, NPC-капитаны), §7 (общие события), `ARCHITECTURE.md` §5

## Правила фазы

- Никакой «вечной физики» NPC: сервер считает **позицию по формуле** (маршрут + скорость + время), физика включается только рядом с игроком.
- Тик офлайн-симуляции — 5 мин, кап 24 ч (P-03, `constants.json → net.fleetOffline`).
- Общее событие — **один** на всех рядом: игроки получают одно и то же письмо/звук, а не каждый свою копию.
- NPC-флот не создаёт товары из воздуха: он **перевозит** уже существующий груз.

## Шаги

### 18.1 · Модель флота
- **Действие:** `GAME_DESIGN/Fleet.json`: сколько NPC-кораблей на маршрут, их класс (лёгкий/средний/тяжёлый), цикл «рейс → продажа → новый рейс», стартовый груз.
- **Готово, когда:** `Fleet.json` описывает NPC-флот: ≥ 1 корабль на каждый из 4 маршрутов; у каждого класс, цикл и груз; все маршруты — существующие из `Routes.json`.

### 18.2 · Офлайн-симуляция
- **Действие:** Серверный `TH_Server/Ships/FleetOffline.lua`: позиция NPC-корабля = f(маршрут, скорость, время) + тик раз в 5 мин; кап 24 ч. Никакой физики в тике.
- **Готово, когда:** Офлайн-тест: 100 тиков подряд — позиция считается детерминированно, без NaN; после 24 ч корабль «засыпает» (позиция не обновляется) — по `constants.json`.

### 18.3 · Продажа NPC-товаров
- **Действие:** NPC-корабли приходят в порт и продают груз по ценам `Prices.json`; игрок может купить. Это источник дефицита, а не «из ничего».
- **Готово, когда:** NPC-груз появляется в магазине и исчезает при продаже; цена — из `Prices.json`; при исчерпании NPC-цикла товар не появляется снова мгновенно (проверяется логом).

### 18.4 · NPC-корабли в мире
- **Действие:** NPC-флот виден в мире: корпуса, паруса, след. Они перемещаются по маршрутам и реагируют на погоду (замедление в шторм).
- **Готово, когда:** В Play видно NPC-корабли на маршрутах (скриншот); в шторм скорость ниже (множитель из `Weather.json`); NPC-корабли не сталкиваются с игроком (уступка).

### 18.5 · Общие события
- **Действие:** `TH_Server/World/WorldEvents.lua`: событие (пиратское нападение, шторм, блокада) рассылается **всем игрокам в радиусе** одним сообщением; у каждого — своя реакция, но событие одно (Bible §7).
- **Готово, когда:** При спавне события 3 игрока в радиусе получают **одно** и то же событие (сверка идентификатора события в логе); копий по числу игроков нет.

### 18.6 · Реакция на событие
- **Действие:** Каждый игрок решает сам: помочь, уклониться, использовать как повод. Награда — по действию (Bible §7: «одно нападение — одно на всех»).
- **Готово, когда:** Минимум 2 варианта реакции (помочь/уклониться) с разными исходами; награда начисляется один раз; тест: два игрока выполнили одно и то же задание — награды не задвоились.

### 18.7 · Нагрузка и лимиты
- **Действие:** NPC-флот не должен съедать бюджет: near-зона — реальные объекты, far-зона — импостеры; лимит частей на шард (60 игроков).
- **Готово, когда:** В near-зоне NPC-корабль — модель, в far — импостер (1 part вместо 40); parts на шард в пределах `constants.json → limits.nearPartsMax`; замер в `STATUS.md`.

### 18.8 · Приёмка и фиксация
- **Действие:** Прогон 24 ч офлайн-симуляции: NPC-корабли ходят, продают, реагируют на погоду; общее событие одно на всех. Тег `v0.19.0`.
- **Готово, когда:** 24 ч симуляции без ошибок; NPC-груз продаётся по ценам из данных; 3 игрока в радиусе получают одно событие; тег `v0.19.0`; бэкап.

- [ ] Общее событие — одно на всех в радиусе.
- [ ] Нагрузка в пределах бюджета, far-зона на импостерах.
- [ ] Тег `v0.19.0`.

## Риски и грабли

- **Вечная физика NPC** — 100 кораблей × физика = лаг. Позиция считается по формуле.
- **NPC создаёт товар из воздуха** — бесконечная экономика; NPC только перевозит.
- **Событие копируется на каждого** — против Bible §7: событие одно.

## Чего в этой фазе НЕ делаем

- Не делаем PvP между NPC-флотом и игроками без участия игроков.
- Не делаем битвы флота между NPC.
- Не делаем торг между NPC-флотами.
