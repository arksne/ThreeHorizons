# Ф3 · Арт-пайплайн (Blender → FBX → Roblox)

> **Цель:** воспроизводимый конвейер: скрипт в Blender → правильный FBX → проверка → импорт в Studio
> без «сюрпризов» с масштабом и пивотом. Пайплайн важнее конкретных моделей: он переживёт проект.
> **Зависит от:** Ф0, Ф2 · **Выход:** `blender/` со скриптами, `validate_assets.py`, `manifest.json` · **Сессий:** 2
> **Канон:** `ART_PIPELINE_BLENDER_KIT.md`, `TEXTURE_PIPELINE.md`, `QUALITY_ASSURANCE.md` (A-1)

## Правила фазы

- Гибрид L0 Hero / L1 Kit / L2 Blockout: **игра не зависит от наличия мешей** — везде фолбэк в боксы.
- Единицы: Blender — метры; Roblox — studs; масштаб применяется импортёром, а не моделью.
- Пивот — центр основания (`base_center`), низ модели на Y=0, фасад смотрит вперёд.
- Жёсткие бюджеты: hero-здание ≤ 12k tri, L1 ≤ 35 %, L2 ≤ 8 % (или импостор).

## Шаги

### 3.1 · Blender: установка и безопасный запуск
- **Действие:** зафиксировать путь к портативному Blender 4.x; скрипт `tools/blender.ps1` с
  `--threads 2` и `PriorityClass = BelowNormal` (иначе CPU 99 %).
- **Готово, когда:** `blender --version` через обёртку отвечает, CPU при рендере ≤ 50 %.
- **Канон:** скилл проекта (грабли Blender).

### 3.2 · Структура `blender/`
- **Действие:** `blender/{scripts,presets,export,renders,validate_assets.py,manifest.json}` +
  `blender/README.md` (как запускать, где что).
- **Готово, когда:** структура есть, `README` объясняет один полный цикл.

### 3.3 · Пресет экспорта
- **Действие:** `blender/presets/export_preset.md` + `export_config.py`: scene unit = 1 м,
  `apply_scale_options='FBX_SCALE_ALL'`, Y-up, forward −Z, `set_origin_base_center()`.
- **Готово, когда:** тестовый куб 1×1×1 м экспортируется, в Studio = 3.571×3.571×3.571 st и стоит на полу.
- **Канон:** `ART_PIPELINE_BLENDER_KIT.md` §«Технические правила» 1–3.

### 3.4 · `blender/scripts/hero_export.py` (каркас)
- **Действие:** CLI: `--style`, `--out`, `--validate`, `--all`. Пока с одной тестовой функцией
  `build_box(name, size_m)`; каркас для будущих моделей зданий/кораблей.
- **Готово, когда:** `python hero_export.py --out blender/export` создаёт FBX + запись в манифест.

### 3.5 · `blender/validate_assets.py`
- **Действие:** проверять каждый FBX: tri ≤ 12k (hero), UV присутствует, ≤ 3 материала, нет
  вырожденных граней, нормали наружу, габариты = заявленным, пивот в основании, LOD-соотношения
  35 % / 8 %.
- **Результат:** `validation.json` + код возврата ≠ 0 при ошибке.
- **Готово, когда:** испорченный FBX (открытые торцы, перевёрнутые нормали) даёт понятные ошибки.

### 3.6 · LOD-конвейер
- **Действие:** `hero_export.py --lod`: Decimate до 35 % и 8 %, суффиксы `_L1`/`_L2`; проверка
  силуэта (совпадение bbox ±5 %).
- **Готово, когда:** L0/L1/L2 у тестового объекта имеют tri в допуске, силуэт не «схлопывается».

### 3.7 · Манифест ассетов
- **Действие:** `blender/manifest.json`: `{name, faction, kind, dimsM, tri:{L0,L1,L2}, materials[],
  files[], createdAt, status}`. Частичный экспорт **мержит** манифест, не затирает.
- **Готово, когда:** экспорт одного объекта не теряет записи остальных.
- **Канон:** `ART_PIPELINE_BLENDER_KIT.md` §«Файлы».

### 3.8 · Приёмка текстурами
- **Действие:** `tools/gen_textures.py` (numpy+Pillow): для начала 3 материала × 3 карты
  (albedo/normal/roughness) 512², палитры строго из `DESIGN_TOKENS.md`; бесшовность проверяется
  тайлингом 3×3.
- **Готово, когда:** 9 PNG, бесшовность визуально проверена, `manifest.json` текстур содержит HEX.
- **Канон:** `TEXTURE_PIPELINE.md`; `DESIGN_TOKENS.md`.

### 3.9 · Сквозной тест «куб → Studio»
- **Действие:** куб 1 м с текстурой: FBX → 3D Importer → `ReplicatedStorage/TH_Art` → Part c
  MeshPart, `Anchored=true`; сверить размер (3.571 st), пивот, материал.
- **Готово, когда:** скриншот в Studio с линейкой-стеной 10 studs, куб стоит ровно.
- **Канон:** `ART_PIPELINE_BLENDER_KIT.md` §«Как это выглядит по шагам» 3–5.

### 3.10 · `docs/PIPELINE.md`
- **Действие:** описать полный цикл: скрипт → FBX → валидатор → импорт руками → id в
  `MeshAssets.lua` → фолбэк. Отдельно — «чего нельзя автоматизировать» (FBX-импорт, модерация).
- **Готово, когда:** новый человек (или агент) проходит цикл по документу без вопросов.

### 3.11 · `preflight -Art`
- **Действие:** добавить в `tools/preflight.ps1` флаг `-Art`: прогон `validate_assets.py` по
  `blender/export/**` + отчёт.
- **Готово, когда:** `preflight -Art` зелёный на тестовом кубе.

### 3.12 · Фиксация пайплайна
- **Действие:** тег `v0.4.0`, запись в DECISIONS «пайплайн экспорта зафиксирован», бэкап.
- **Готово, когда:** всё вышеперечисленное воспроизводится с чистой папки.

## Риски и грабли

- **Пивот «как получилось»** — главная причина «утопленных» зданий. Проверка в валидаторе обязательна.
- **FBX-импорт нельзя сделать из Luau** — в пайплайне всегда есть ручной шаг; не строить иллюзий
  об автоматизации.
- **Модерация текстур занимает время** — до загрузки живём на `Color+Material` фолбэке.
- **Blender жрёт CPU** — только через обёртку с `--threads 2`.

## Чего в этой фазе НЕ делаем

- Не делаем все 30+ ассетов — только каркас пайплайна и тестовый куб (ассеты — Ф4).
- Не настраиваем Steam-экспорт и не трогаем Roblox-логику.
