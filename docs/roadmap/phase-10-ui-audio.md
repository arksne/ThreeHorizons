# Ф10 · UI и звук v0.1

> **Цель:** игра выглядит и звучит как Three Horizons, а не как тестовая сцена: единый стиль
> «пергамент + латунь», понятные окна, HUD, базовый звуковой слой.
> **Зависит от:** Ф9 (механики, которым нужен UI) · **Выход:** UI-кит + 5 окон + HUD + 12–15 звуков · **Сессий:** 2–3
> **Канон:** `UX_DESIGN_SPEC.md`, `DESIGN_TOKENS.md` (UI-токены/шрифты), `AUDIO_DESIGN_BIBLE.md`,
> `SPECS_COMBINED.md` (PLATFORM/ANIMATION), `VISUAL_DESIGN_BIBLE.md` §интерьеры/UI

## Правила фазы

- Один шаблон окна: **список слева → детали справа → действие внизу**. Не изобретать на каждое окно.
- Токены: `PARCHMENT #E8DCC0`, `PARCHMENT_DARK #CBB98F`, `BRASS #B08D3E` (рамка 2px), `INK #1E1A14`,
  радиус 4px; заголовки — serif (валидные: `Garamond`, `Merriweather`), тело — sans 14–16px.
- Кнопки на тач ≥ 44 pt; мобильные окна — крупные строки, минимум скролла.
- Ресурс = иконка + цвет (дальтонизм), не только цвет.
- Звук — только original/licensed; именование `TH_AU_<faction>_<name>_v1`.

## Шаги

### 10.1 · UI-кит
- **Действие:** `TH_Client/UI/Kit.lua`: цвета-токены, шрифты, рамки, кнопки (3 состояния), поле
  ввода, скролл-лист, тост. Всё — из `DESIGN_TOKENS.md`, ни одного «похожего» цвета.
- **Готово, когда:** демо-окно собрано из `Kit.lua` **без единого ручного цвета**:
  `grep` по файлам UI не находит hex-литералов кроме токенов из `DESIGN_TOKENS.md`;
  у кнопки 3 состояния (обычная/наведение/нажата) — видно на превью; gate A-1 по UI пройден.

### 10.2 · Шаблон окна
- **Действие:** `Window.lua`: заголовок serif + рамка BRASS, левый список, правая панель деталей,
  нижняя строка действий, закрытие по Esc/тапу вне.
- **Готово, когда:** на шаблоне `Window.lua` собираются **все 5 окон** без правок самого
  шаблона (только данные); закрытие работает по Esc и по тапу вне окна — проверено в Play;
  превью 5 окон лежат в `ART_ASSETS/screenshots/ui/`.

### 10.3 · Окно торговли
- **Действие:** список товаров с иконкой/ценой/запасом, детали (описание, цепочка), кнопки
  купить/продать с подтверждением суммы; ошибки сервера — тостом.
- **Готово, когда:** сделка из UI идёт через `NetAPI`, цена = серверная, спам блокируется.

### 10.4 · Окно склада/инвентаря
- **Действие:** груз, трюм, вес/объём, передача между складом и трюмом; лимиты видны.
- **Готово, когда:** перегруз **не проходит** (сервер отклоняет, клиент показывает причину);
  количество **сходится с сервером** после передачи 5 предметов склад→трюм (сверка чисел
  в Output до/после); вес/объём и лимиты видны в окне.

### 10.5 · Окно квестов
- **Действие:** активные/завершённые, условие прогрессом (5/5), награда; кнопка «сдать» активна
  только при выполнении.
- **Готово, когда:** **двойная сдача невозможна**: кнопка «сдать» активна только при выполнении
  условия, после сдачи прогресс = 5/5 и кнопка неактивна; награда приходит **ровно один раз**
  (повторный вызов сервера не начисляет второй раз — проверяется в логе).

### 10.6 · Окно карты
- **Действие:** карта мира из Ф2 (PNG), маркеры: столица, причал, игрок, маршрут; туман войны
  (`mapFog` в профиле).
- **Готово, когда:** карта открывается по **M**; маркеры **совпадают с координатами** Ф2
  (каждый маркер на своём острове — сверка с `WORLD_COORDINATES.csv`); туман войны
  (`mapFog` в профиле) открывается по мере посещения и сохраняется после rejoin.

### 10.7 · HUD
- **Действие:** деньги, топливо, курс/компас, подсказки `TH_UI_Hint` (один стиль, внизу по центру),
  предупреждения (шторм/топливо).
- **Готово, когда:** HUD **не перекрывает** открытое окно (проверка на превью);
  обновление раз в 0.25–0.5 с (частота замеряется в Output); на мобильном разрешении
  цифры читаются (минимальный размер текста ≥ 14 px, по `constants.json → platform`).

### 10.8 · Управление и адаптивность
- **Действие:** глаголы E/F/M/Tab(I)/H; тач-кнопки ✋⚓🗺🎒 64 pt; геймпад — план (X/Y/View/LB);
  авто-скрытие подсказок на тач.
- **Готово, когда:** все действия доступны мышью, тачем и (по плану) геймпадом.
- **Канон:** `UX_DESIGN_SPEC.md` §глаголы; `SPECS_COMBINED.md` §PLATFORM.

### 10.9 · Доступность и читаемость
- **Действие:** контраст текста на пергаменте, размеры шрифта, дублирование цветов иконками,
  проверка на 1280×720 и на телефоне.
- **Готово, когда:** чек-лист «читается без зума» пройден, скриншоты 3 разрешений.

### 10.10 · Звук: SFX v0.1
- **Действие:** 12–15 звуков: UI (пергамент, латунь), шаги, ветер, порт/рынок, скрип снастей,
  двигатель (55 Гц + шум, low-pass); нормализация до −12 dBFS; 3D-источники только у важных объектов.
- **Готово, когда:** 12–15 звуков на месте, нормализация **≤ −12 dBFS** (проверяется
  замером пиков), 3D-источники только у важных объектов (не более 5 одновременных);
  **«стены шума» нет**: в порту/на рынке суммарно ≤ 4 источника; Playwright/Play-прослушка
  по зонам зафиксирована в `STATUS.md`.

### 10.11 · Музыка v0.1
- **Действие:** 3 темы-заглушки (Арквейн/порт/море) в стиле из `AUDIO_DESIGN_BIBLE.md`, 70–95 BPM,
  струнные+духовые; только original/licensed; кроссфейд по зоне 2–3 с.
- **Готово, когда:** 3 темы (Арквейн / порт / море), 70–95 BPM по `AUDIO_DESIGN_BIBLE.md`,
  только original/licensed (источник указан в `STATUS.md`); кроссфейд по зоне **2–3 с без щелчка**
  (прослушка в Play); громкость регулируется в настройках и сохраняется после rejoin.

### 10.12 · Мобильный прогон и фиксация
- **Действие:** Device Simulator: телефон/планшет — пройти цикл Ф9, проверить кнопки, окна, FPS;
  тег `v0.11.0`, бэкап, CHANGELOG.
- **Готово, когда:** на мобилке цикл проходится без «не нажимается», FPS ≥ 30.

## Риски и грабли

- **`Enum.Font.Serif` не существует** — брать `Garamond`/`Merriweather`, иначе selene/рантайм ругнётся.
- **Свои цвета «на глаз»** — только токены, иначе стиль расползётся.
- **Окна-снежинки** — каждое со своим шаблоном = вдвое больше работы; строго один шаблон.
- **Звук без микшера** — через 10 минут игры «стена шума»; громкости по группам сразу.

## Чего в этой фазе НЕ делаем

- Полного набора окон из §17 (11 окон) — только 5, остальные после альфы.
- Локализации, катсцен, сложной анимации UI.
