# Ф11 · Интерьеры (помещения корабля и зданий)

> **Цель:** Интерьер корабля — обязателен по Bible §4: рубка, каюта капитана, машинное, трюм, кубрик, оружейная. Плюс помещения зданий: дом, таверна, мастерская, склад, торговая контора. Сейчас в плане — «болванка», то есть пусто.
> **Зависит от:** Ф10 (корабли), Ф7 (ассеты)
> **Канон:** Bible §4 (интерьер обязателен), `BUILDING_CATALOG.md`, `MASTER_SCALE_SPEC.md` §2

## Правила фазы

- Планировка — **данные** (`GAME_DESIGN/Interiors.json`), не код: комнаты, проёмы, мебель, точки взаимодействия.
- Высота помещений по канону: жилой 2.7 м, трюм/машинное 3.2 м; дверь 1.0×2.1 м.
- Один интерьер = один модуль Luau; боксы-фолбэк обязателен (игра не зависит от мешей).
- Каждое помещение — с **освещением** (лампы) и точкой входа: игрок должен понять, где оказался.

## Шаги

### 11.1 · Схема помещений корабля
- **Действие:** 6 помещений среднего корпуса 32×10 м с площадями и назначением: рубка (капитан+штурман), каюта капитана, машинное (инженер), трюм (груз), кубрик (экипаж), оружейная (канонир). У каждого — высота и площадь в м².
- **Готово, когда:** `GAME_DESIGN/Interiors.json` содержит 6 помещений корабля; у каждого площадь, высота (2.7 или 3.2 м по назначению) и ≥1 точка взаимодействия; валидатор проходит.

### 11.2 · Схема помещений зданий
- **Действие:** 5 помещений: дом (комната + кухня), таверна (зал + стойка), мастерская (цех + станок), склад (зал + стеллажи), торговая контора (торговый зал).
- **Готово, когда:** В `Interiors.json` — 5 помещений зданий; суммарно 11 помещений; по каждому проверка: площадь ≥ 9 м², есть дверь 1.0×2.1 м.

### 11.3 · Планировка в сетке 1 м
- **Действие:** Расстановка стен и проёмов по сетке 1 м: координаты комнат, дверные проёмы, окна. Чистые данные, без привязки к конкретной модели.
- **Готово, когда:** Каждое помещение имеет сетку 1 м: стены по границам комнат, проёмы — список (стена, позиция, тип). Проверка: все комнаты связаны проёмами, тупиков нет.

### 11.4 · Мебель и наполнение
- **Действие:** Стол, стул, кровать, шкаф, сундук, стеллаж, станок, стойка — по `MASTER_SCALE_SPEC.md` §2 (мебель: стол 0.75, стул 0.45, кровать 2.0×0.9).
- **Готово, когда:** Список мебели в `Interiors.json` с габаритами из канона; для каждого предмета — код из `constants.json → art` (не выдуманный); ни одна мебель не выходит за периметр комнаты.

### 11.5 · Модуль интерьера `TH_Shared/Generators/InteriorGenerator.lua`
- **Действие:** Собирает помещение по данным: пол, стены, потолок, двери, окна, мебель, лампы. Фолбэк — боксы (игра работает без мешей).
- **Готово, когда:** `luau-compile` проходит; генератор собирает помещение из `Interiors.json` (офлайн-тест: число частей > 0, комнаты не пересекаются, двери в проёмах).

### 11.6 · Точки взаимодействия
- **Действие:** Каждое помещение имеет 1–3 интерактивные точки (навигация, отдых, крафт, торговля) — они связывают интерьер с механиками (Ф16).
- **Готово, когда:** Список интеракций в `Interiors.json`; каждая ссылается на существующую механику (проверка ссылок валидатором); минимум 1 интеракция в помещении, кроме коридора.

### 11.7 · Рубка и управление кораблем
- **Действие:** Рубка — место, откуда игрок рулит: штурвал, компас, карта, окно вперёд. Связать с управлением из Ф10.
- **Готово, когда:** Рубка присутствует в генераторе корабля (Ф10); в ней есть штурвал-интеракция и окно по носу; скриншот рубки в `ART_ASSETS/screenshots/`.

### 11.8 · Приёмка и фиксация
- **Действие:** Пройти по всем 11 помещениям: войти, осмотреться, выйти. Проверить высоту потолка на глаз, ширину двери, наличие света.
- **Готово, когда:** По каждому из 11 помещений — скриншот; потолок 2.7/3.2 м читается; дверь выглядит проходимой для 1.7 м персонажа; тег `v0.9.0`; бэкап.

## Definition of Done фазы

- [ ] `GAME_DESIGN/Interiors.json`: 11 помещений с планировкой по сетке 1 м.
- [ ] `InteriorGenerator.lua` собирает помещение из данных, фолбэк — боксы.
- [ ] Мебель по габаритам канона; интеракции привязаны к механикам.
- [ ] 11 скриншотов помещений, высоты читаются.
- [ ] Тег `v0.9.0`.

## Риски и грабли

- **Интерьер без выхода** — игрок застревает: у каждой комнаты обязан быть путь наружу.
- **Потолок ниже 2.7 м** — «прижимает голову»; мерить, а не угадывать.
- **Предметы мимо стен** — коллизии мебели сдвигают, а не двигают стены.

## Чего в этой фазе НЕ делаем

- Не делаем многоэтажные дома и вертикальные лестницы — это после альфы.
- Не делаем анимацию NPC внутри помещений.
- Не делаем интерьеры для малых поселений (Ф20).
