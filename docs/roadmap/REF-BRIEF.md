## ЧАСТЬ 1. Общие указания (применить ко всем картинкам)

**Стиль.** Stylized Realism + Medieval Maritime + Vintage Exploration.
Реалистичные пропорции, но упрощённые формы. Средневековая морская техника и корабли.
Винтажная палитра, как на старых гравюрах и лоцманских картах: приглушённые тона, лёгкая
выцветлость, тёплые тени, лёгкая зернистость плёнки.

**НЕ делать:** фэнтези, стимпанк, мультяшно/аниме, гиперреализм, неон и киберпанк,
современность, Plastic-игрушечность, яркий поп-арт.

**Кадр.** Один объект (или группа) в центре, **светлый однотонный фон** (тёплый серый
#E8DCC0 или очень светлый небо), **вид в 3/4 слегка сверху**, плюс маленькая
проекция сверху и **линейка-эталон** рядом с объектом (для масштаба).

**Масштаб.** Указывать реальный размер в метрах. Человек = 1.7 м. Дверь = 1.0×2.1 м.
Потолок жилой = 2.7 м. Улица главная 8 м, второстепенная 4 м. Зазор между домами ≥ 3 м.

**Свет.** Мягкий дневной, тёплый, с читаемыми тенями. Без HDR-блеска.
Фракция определяет цвет температуру: Арквейн 6500K (нейтрально-прохладный),
Вальмер 5600K (светлый день), Гринвальд 5200K (тёплый).

**Палитра — строго по HEX.** Не подбирать «похожие» цвета.

| Фракция | HEX |

| Арквейн (технологии, графит) | ARK_GRAPHITE #2B2E33 · ARK_STONE #5A5C60 · ARK_WOOD_DARK #4A3226 · ARK_BURGUNDY #6E2A2A · ARK_COPPER #8C5A3B · ARK_STEEL #9AA2A8 · ARK_PLASTER #C9C2B4 |
| Вальмер (вода, торговля, известняк) | VAL_LIMESTONE #EDE6D3 · VAL_CREAM #D9C9A8 · VAL_SAND #B99B6B · VAL_TEAL #4E7E8C · VAL_SEA #2E4E7E · VAL_BRONZE #A87F3F · VAL_WHITE #F5F1E6 |
| Гринвальд (земля, олива) | GRN_OLIVE #5A6B3C · GRN_FOREST #3E5230 · GRN_WOOD #6B4A2E · GRN_BEIGE #D8C9A3 · GRN_STRAW #C2A35C · GRN_TERRA #A55A35 · GRN_STONE #8A8578 |
| Общие / UI | INK #1E1A14 · PARCHMENT #E8DCC0 · PARCH_DARK #CBB98F · BRASS #B08D3E · WOOD_UI #3A2A1C · DANGER #8C2B1B · FOCUS_BLUE #2E4E7E |

**Персонажи.** Все — люди, без магии и сверхсилы. **Никакой «злодейской» внешности**:
антигонистов отличают костюм и манеры, а не физиология. Лицо обычное, без уродств.
Возраст героев 24 / 26 / 23. Одежда: Вейл — красно-коричневая кожа, инженер;
Морвей — синий камзол, торговля; Эшфорд — зелёный плащ, следопыт.

**Прочее.** Одинаковая стилистика всех кадров. Тени мягкие. Никаких водяных знаков,
логотипов, надписей на латинице. На табличках — только абстрактные символы.

## ЧАСТЬ 3. Как отдавать результат

1. **Формат:** PNG, квадрат 2048×2048 (или 1920×1920), светлый фон.
2. **Имя файла:** `<id>.png` — ровно как id в списке. Итого 57 файлов.
3. **Куда:** `ART_ASSETS/refs/`. По одной картинке на класс, с 2–3 ракурсами **на одном листе**.
4. **Порядок:** группы A→I, внутри группы — как в таблице. Не перемешивать группы.
5. **Отдельно:** 3 файла общих — `STYLE_BOARD_ARKVEIN.png`, `STYLE_BOARD_VALMER.png`,
   `STYLE_BOARD_GRINWALD.png` — палитра фракции: все 7 цветов крупными плошками + 2–3
   готовых дома и 1 персонаж в этой палитре.
6. **Плюс 4 общих кадра:** `WORLD_OVERVIEW.png` (три острова над облачным морем, вид сверху),
   `SHIP_LINEUP.png` (все 3 корпуса в ряд, чтобы читалась разница в размере),
   `STREET_SCALE.png` (улица 8 м с домами по бокам и фигурой человека 1.7 м — эталон масштаба),
   `UI_SHEET.png` (все 5 UI-элементов).

**Итого: 57 + 3 + 4 = 64 файла.**
