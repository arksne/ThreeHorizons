# Ф15 · Механики v0.1 (экономика, NPC, квест)

> **Цель:** один полный игровой цикл: выбрал фракцию/героя → пришёл в город → взял квест → купил
> сырьё → сделал товар → продал → получил деньги → сохранился. Всё на сервере, всё идемпотентно.
> **Зависит от:** Ф7, Ф9, Ф9
> **Канон:** Bible §5–§8, `SPECS_COMBINED.md` §SECURITY/BALANCING, `ARCHITECTURE.md` §2–§4,
> `UX_DESIGN_SPEC.md` (глаголы)

## Правила фазы

- Любая ценность (деньги, груз, награда) меняется только на сервере; клиент — намерение.
- Каждая транзакция — `txId`; повтор = no-op. Награда квеста — флаг в профиле, не «по событию».
- Числа баланса — из `Prices.json` со статусом `PROPOSED`; после игры — пересмотр и `APPROVED`.
- Минимум систем: 1 цепочка, 2 товара, 1 стратегический ресурс, 3 NPC, 1 квест.

## Шаги

### 15.1 · Онбординг: фракция и герой
- **Действие:** на первом входе — выбор фракции (3) и героя (пара М/Ж); запись в профиль;
  повторный вход не спрашивает.
- **Готово, когда:** выбор сохраняется, rejoin возвращает тот же герой; данные из `Factions.json`/`Heroes.json`.

### 15.2 · Кошелёк и транзакции
- **Действие:** `Wallet.lua`: баланс, `deposit/withdraw` в одной транзакции, журнал, `txId`;
  стартовый капитал из `Prices.json`.
- **Готово, когда:** нельзя уйти в минус; двойной вызов с одним `txId` не удваивает; тест проходит.
- **Канон:** `SPECS_COMBINED.md` §SECURITY 3, 8; `ARCHITECTURE.md` §4.

### 15.3 · Производство v0.1
- **Действие:** 2 рецепта из `Goods.json`: дерево→доски, зерно→мука; станок (мастерская) — время,
  вход/выход, очередь; статус в профиле.
- **Готово, когда:** 2 рецепта из `Goods.json` (дерево→доски, зерно→мука) запускаются
  на станке в мастерской: вход списывается **в момент старта**, выход выдаётся **ровно один раз**
  по таймеру (повторный запрос не выдаёт второй раз); статус виден в профиле;
  офлайн-тест в `tools/test.ps1` PASS.

### 15.4 · Магазин NPC
- **Действие:** лавка на площади: покупка/продажа 3–4 товаров, прайс только серверный, лимит
  операций 5/с (rate-limit), UI-заглушка (полный UI — Ф13).
- **Готово, когда:** цена на клиенте не влияет на сделку; спам блокируется; груз появляется в трюме.
- **Канон:** `world/TRADE_ROUTES.md` (что чем торгует); `SPECS_COMBINED.md` §SECURITY 2.

### 15.5 · Стратегический ресурс
- **Действие:** эфирное топливо: ограниченный запас у NPC, недельный лимит покупки, цена растёт
  при выборке; расход — кораблём (Ф9.4).
- **Готово, когда:** топливо нельзя купить «бесконечно»; цифры из `Goods.json` (`strategic: true`).
- **Канон:** Bible §6; `DESIGN_TOKENS.md` (цвет топлива — для UI-иконки).

### 15.6 · NPC с расписанием
- **Действие:** 3 NPC (торговец, мастер, начальник причала): позиции утро/день/ночь, диалог-текст,
  реакция на квест; вне видимости — агрегированное состояние (без полной симуляции).
- **Готово, когда:** в 8:00/14:00/22:00 NPC на своих точках; диалог открывается по E.
- **Канон:** Bible §7; `ARCHITECTURE.md` §2.

### 15.7 · Квест v0.1
- **Действие:** «принеси 5 досок мастеру»: выдача, условие, сдача, награда деньгами + предмет;
  флаг `quests.done` + `txId`; повторная сдача — отказ.
- **Готово, когда:** квест проходится за 5 минут, награду нельзя получить дважды.
- **Канон:** Bible §7; `SPECS_COMBINED.md` §SECURITY 3.

### 15.8 · Собственность (минимум)
- **Действие:** покупка мастерской на площади (одна на игрока): даёт доступ к станку и пассивный
  доход 40/игрочас (число PROPOSED), владение в профиле.
- **Готово, когда:** после rejoin купленная мастерская **восстанавливается** из профиля;
  второй игрок **не может** купить ту же мастерскую (владелец — первый покупатель);
  пассивный доход начисляется **только владельцу** (число 40/час — PROPOSED, помечено в UI);
  офлайн-тест владения и дохода PASS.

### 15.9 · Профессии (рост)
- **Действие:** 2 навыка (торговля, ремонт): опыт за действия, уровни 1–3 с порогами из
  `Professions.json`; влияние — скидка/скорость крафта.
- **Готово, когда:** действия повышают навык, эффект виден в цифрах, после перезахода сохраняется.

### 15.10 · Сохранения всего цикла
- **Действие:** профиль: деньги, груз, собственность, квесты, навыки, фракция, герой; autosave 120 с +
  save-on-leave + `BindToClose`; миграции версии.
- **Готово, когда:** leave/rejoin **3 раза подряд** — деньги, груз, собственность,
  квесты, навыки, фракция, герой **не потеряны и не удвоены** (сверка снапшота профиля
  до/после: значения равны); `BindToClose` отрабатывает (в логе видно сохранение при выходе).

### 15.11 · Аудит и аналитика
- **Действие:** `Audit.lua` — журнал стратегических операций (топливо, крупные суммы, награды);
  приватная агрегированная аналитика (без PII): сессии, квесты, крафты.
- **Готово, когда:** по журналу можно восстановить «кто получил награду и когда».
- **Канон:** `SPECS_COMBINED.md` §SECURITY 7; `BALANCING_SPEC` (аналитика приватная).

### 15.12 · Экономический прогон
- **Действие:** сценарий: старт → квест → продажа → крафт → продажа; замерить время цикла, доход/час,
  «узкие места» (что дороже всего).
- **Готово, когда:** цикл проходится без эксплойтов (нельзя разбогатеть за 2 минуты), цифры записаны.

### 15.13 · Сверка баланса
- **Действие:** сравнить факт с `Prices.json`; поправить данные (не код), обновить статусы
  `PROPOSED → TESTED`; записать в DECISIONS, что изменили.
- **Готово, когда:** таблица цен и времени отражает факт, тест-цикл остаётся проходимым.

### 15.14 · Гейты S-1 и R-1
- **Действие:** 2 клиента + сервер: весь цикл, спам-тест, rejoin, Output чистый, Remote ≤ 60/с.
- **Готово, когда:** чек-лист S-1 закрыт **с evidence**: скриншот/лог каждого пункта
  (2 клиента + сервер, спам-тест, rejoin, чистый Output, Remote ≤ 60/с); CHANGELOG заполнен,
  бэкап `backups/<версия>_<дата>/` сделан — всё в `docs/STATUS.md` как «Проверено фактически».

### 15.15 · Фиксация
- **Действие:** тег `v0.10.0`, бэкап, `STATUS.md` → «играбельный цикл готов».
- **Готово, когда:** новая сессия может пройти цикл по документу без подсказок.

## Definition of Done фазы

- [ ] Онбординг, кошелёк с `txId`, 2 рецепта, магазин, стратегический ресурс.
- [ ] 3 NPC с расписанием, 1 квест с защитой от повтора, 1 собственность, 2 навыка.
- [ ] Всё сохраняется после rejoin.
- [ ] Экономический прогон с цифрами, баланс сверен.
- [ ] S-1/R-1 закрыты, тег `v0.10.0`.

## Риски и грабли

- **Награда «по событию»** — дюп при лагах; только флаг в профиле + `txId`.
- **Баланс из головы** — числа только из данных, статус PROPOSED до прогона.
- **Собственность «одна на всех»** — CAS через UpdateAsync, иначе двойная продажа.
- **NPC, которые ходят всегда** — вне радиуса только агрегат, иначе сервер умрёт на 60 игроках.

## Чего в этой фазе НЕ делаем

- Гильдий, аукционов, войн фракций, PvP, захвата кораблей, кросс-шардовых ивентов.
- Полного UI — только функциональные заглушки (Ф13).
