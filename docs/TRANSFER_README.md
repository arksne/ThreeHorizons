# TRANSFER README — пакет контекста для ИИ-артиста персонажей

Версия проекта на момент передачи: **v1.4 (2026-11-02)**.
Этот архив — ответ на `ЗАПРОС_ФАЙЛОВ_ThreeHorizons.md`.

## Что внутри

```
docs/                         — 27 документов канона (Bible, токены, масштабы, пайплайн, QA, реестр, CHANGELOG, STATUS)
_refs/ref01..ref09.png        — 9 референс-атласов стиля (50 МБ, смотреть ПЕРВЫМИ)
blender/*.py                  — рабочий пайплайн сборки ассетов (hero_export.py — образец)
blender/export/**/*.fbx       — 63 FBX: 26 hero-моделей × LOD (дома, башни, мастерские, усадьбы, склады,
                                корабли, стена, ворота, причал) + manifest.json с трис-числами
tools/gen_textures.py         — генератор процедурных PBR-текстур (образец)
tools/render_preview.py       — офлайн-рендер процедурных моделей
tools/harness/                — офлайн-запуск Luau-генераторов без Studio
tools/luau/luau.exe           — CLI Luau (компиляция/анализ конфигов)
tests/*.lua                   — 6 тестов проекта
GAME_DESIGN/*.json            — корабли и товары (чистые данные)
ROBLOX_IMPLEMENTATION/src/…/Config/  — Palettes.lua, Heroes.lua, Factions.lua, MeshAssets.lua (рантайм-канон)
ART_ASSETS/textures/          — 66 PBR-текстур (22 материала × albedo/normal/roughness), 512²
ART_ASSETS/previews3d/        — рендеры hero-моделей + 6 кадров улиц трёх столиц
ART_ASSETS/previews/          — рендеры процедурных моделей
docs/AI_PROMPT_CHARACTERS.md  — сам промт-задание (12 частей)
```

## Чего в архиве НЕТ (намеренно)

- `tools/blender/` — портативный Blender 4.5.15 (~900 МБ). Поставь свою копию той же версии.
- `backups/` — снапшоты проекта.
- `build/` — дампы офлайн-харнесса.

## Кто что делает (граница зон)

| Зона | Кто | Статус |
|---|---|---|
| Персонажи, одежда, броня, оружие, носимые инструменты, NPC-наряды | **получатель этого пакета** | не начато |

Полная таблица с спорными случаями (бочка на улице vs бочка в руке, пушка корабельная vs мушкет) —
`docs/AI_PROMPT_CHARACTERS.md`, **Часть 0.1**. Пересекаться нельзя: двойная работа ломает единый стиль.

Куда сдавать: `ART_ASSETS/characters/<faction>/` + `ART_ASSETS/characters/manifest.json`.
Наши каталоги (`blender/export/`, `docs/ASSET_REGISTRY.md`, `MeshAssets.lua`) не редактировать —
интеграцию в Roblox делаем мы.

## Как проверить, что распаковалось верно

1. `docs/THREE_HORIZONS_PROJECT_BIBLE.md` — первая строка «Версия 1.4.0…».
2. `blender/export/manifest.json` — `"count": 26`, у каждого ассета L0/L1/L2.
3. `ART_ASSETS/textures/manifest.json` — `"count": 66`.
4. `_refs/` — ровно 9 PNG, каждый ~3.5–4 МБ.

## Правила приёмки (кратко)

Полный гейт — в `docs/QUALITY_ASSURANCE.md`; краткий — `docs/AI_PROMPT_CHARACTERS.md`, часть 8.
Главное: FBX-файл, а не концепт; 1 м = 3 studs (рост 1.70 м); R15; pivot в основании/рукояти;
L0 ≤ бюджета из промта; палитра по `DESIGN_TOKENS.md`; есть превью и строка в манифесте.

## Статус смежных работ (чтобы не пересекаться)

- Здания/окружение/корабли: **26 hero-моделей готовы** (см. `blender/export/manifest.json`),
  в Roblox ещё не импортированы — `MeshAssets.Meshes` пуст, работает фолбэк на процедурные боксы.
- Текстуры сгенерированы, в Blender применены; в Roblox не загружены (`MaterialConfig.TEXTURE_IDS` пуст).
- Персонажи/одежда/оружие — **твоя зона**, в проекте пока ничего нет, кроме конфигов и промта.
