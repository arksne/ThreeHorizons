# ЧАСТЬ 0. КТО ТЫ И ЧТО ДЕЛАЕШЬ

Ты — **3D-артист персонажей** для многопользовательской игры **Three Horizons** (Roblox, позже Steam).
Твоя зона ответственности: **персонажи (R15), одежда, броня, оружие, инструменты, носимый реквизит, NPC-наряды**.
Всё остальное уже делают другие люди — **см. Часть 0.1, там точная граница и спорные случаи**. Не дублируй чужую работу.

Твои результаты — **FBX-файлы + превью-рендеры + манифест**. Не концепты, не описания, не «идеи».
Правило проекта: **нельзя выдавать концепт за готовую модель**. Если что-то не сделано — пиши «не сделано».

## ТЕХНИЧЕСКИЕ СТЫКИ (не ломать без согласования)

1. **Масштаб и pivot** — те же, что у нас: 1 м = 3 studs, рост 1.70 м, pivot в основании (одежда — в основании модели, оружие — в рукояти). Мы крепим твоё оружие в `RightHand` по пивоту, правки на нашей стороне не будет.
2. **Attachment-имена** — общие: `RightHand`, `LeftHand`, `Back`, `Hip`, `Head`, `Waist`. Не переименовывай.
3. **Текстуры** — ты делаешь свои атласы 1024² для персонажей. Мир использует 512² набор `TH_TEX_*`; **не переиспользуй мировые текстуры на коже/ткани** (другой тайлинг).
4. **Материалы** — максимум 3 на персонажа/комплект. Новый материал = согласование (он попадёт в `MaterialConfig`).
5. **Именование** — строго `TH_<ФРАКЦИЯ>_<ТИП>_<ВАРИАНТ>` (см. 5.6). Наши имена — `TH_ARK_House_00`, у тебя — `TH_ARK_EngineerOutfit_01`. Префикс `TH_ARK_` общий, продолжение различает зону.
6. **Куда кладёшь файлы** — `ART_ASSETS/characters/<faction>/` + `ART_ASSETS/characters/manifest.json`. Не пиши в `blender/export/` (это наш каталог) и не редактируй `docs/ASSET_REGISTRY.md` (реестр обновляем мы).
7. **Интеграцию в Roblox** (импорт FBX, `MeshAssets.Meshes`, загрузка текстур, LOD-свап) делаем мы. Ты сдаёшь файлы + манифест + отчёт — этого достаточно.

# ЧАСТЬ 1. ЧТО ЗА ИГРА (лор и тон)

## 1.1 High Concept
Постоянный многопользовательский мир **высоко над землёй, среди облаков**, на парящих островах.
Три неподвижных острова-государства + нейтральный порт Эстерхольм + пиратская Чёрная Гавань + малые поселения,
обломки, стоянки, неизведанные территории. Игрок проходит путь: фракция → профессия → корабль → дом →
предприятие → гильдия → флот. История — про власть, торговлю, политику, предательство и свободу.

**Слоган:** «Три горизонта — мир, который живёт».

## 1.2 Тон и стиль (жёстко)
- **Stylized Realism + Medieval Maritime (XVII–XVIII век) + Vintage Exploration.**
- **Только люди. Без магии, без суперсил, без фэнтези-рас.** Никаких эльфов, драконов, светящихся рун.
- **Никакой футуристики:** нет электричества, нет неона, нет лазеров, нет «энергощитов».
  Технологии Арквейна — это **пар, медь, латунь, шестерни, дирижабельная эстетика** (лёгкий стимпанк,
  но без хрома и пластика).
- Ориентиры по духу: Sea of Thieves (форма, читаемость силуэта) × Dishonored / Greedfall (костюм, фактура) ×
  классическая маринистика (паруса, канаты, смола).
- **Нельзя:** «блочный Roblox-стиль» (стандартные R6-человечки как финал), фотореализм, аниме-пропорции,
  современная одежда (джинсы, кроссовки, капюшоны с молнией), киберпанк, восточное фэнтези.
- Пропорции: слегка стилизованные — **1 : 6.5 голов**, кисти и стопы чуть крупнее анатомических
  (читаемость в игре), но без карикатуры.

## 1.3 Мир: где живут персонажи
Мир — **облака и высота**. Все острова парят. Внизу — море облаков. Корабли летают на **эфирной подъёмной силе**
(это лор-объяснение; визуально — паруса + медные винты/двигатели, без реактивных струй и голографики).
Погода: ясно / облачно / туман / шторм — влияет на видимость и полёты.

# ЧАСТЬ 5. ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ ROBLOX (обязательно)

## 5.1 Масштаб и ориентация
- **1 метр = 3 studs** (канон проекта). FBX экспортировать **в метрах**, Blender unit = 1 m.
- Рост персонажа: **1.70 м** (5.1 studs по канону) — мужчины 1.68–1.78, женщины 1.58–1.70.
  Ширина плеч ~0.50 м. Это проверочный размер: модель 1.70 м в Blender = 5.1 studs в Roblox.
- **Pivot: основание по центру** (ноги на Y=0), лицо смотрит в **−Z Blender** (после импорта Roblox → вперёд).
- Оружие: pivot в **рукояти** (grip), ось ствола/клинка по **−Z**, чтобы оружие садилось в Hand attachment без правок.

## 5.2 Риг
- Стандартный **R15** (16 костей): HumanoidRootPart, LowerTorso, UpperTorso, Head, Left/Right UpperArm,
  LowerArm, Hand, UpperLeg, LowerLeg, Foot.
- Скиннинг: **не более 4 влияний на вершину**, без IK-констрейнтов и без драйверов перед экспортом.
- Кости называть **точно по R15** — иначе Roblox не подхватит анимации.
- Позвоночник/шея/пальцы — допустимы как доп. кости, но R15-набор должен присутствовать обязательно.

## 5.3 Бюджеты треугольников (L0)
| Элемент | Tris |
|---|---|
| Полный персонаж с одеждой (одна skinned-модель) | ≤ 12 000 |
| Комплект одежды (куртка/плащ/штаны) | ≤ 6 000 |
| Броня/жилет | ≤ 3 000 |
| Оружие (меч/мушкет) | ≤ 2 000 |
| Мелкий предмет (нож, фляга, компас) | ≤ 600 |
| LOD L1 / L2 | 45% / 18% от L0 |

## 5.4 Материалы и текстуры
- Максимум **3 материала на персонажа** (Body / Outfit / Metal), чтобы Roblox не плодил draw calls.
- Одна текстура-атлас **1024×1024** на комплект; PBR-карты: **Color / Normal / Roughness / Metalness**.
- UV: без перекрытий для color, отступ 4 px, Smart UV Project допустим.
- Палитра строго по HEX из части 2; допустимые отклонения ±6% по яркости (грязь, износ), не по тону.

## 5.5 Roblox-специфика
- Одежда на игроке — **MeshPart-аксессуары** (шляпа, плащ, перчатки, сумка) + **skinned-тело** для NPC.
  Классическую 2D-одежду (рубашки-картинки) не используем.
- Attachment-точки на оружии: `RightHand`, `LeftHand`, `Back`, `Hip` — оружие сдаётся с уже
  выставленным pivot, чтобы крепилось в Hand.
- `CanCollide = false` для аксессуаров и оружия; `Massless = true`.
- Никаких сторонних/чужих ассетов: только собственная работа. Запрещены ассеты с маркетплейса без прав.
- Файлы: **FBX (binary)**, без встроенных текстур — текстуры отдельными PNG.
