## 1. High Concept (APPROVED)
Многопользовательский постоянный мир высоко над землёй среди облаков. Три неподвижных облачных острова-государства + нейтральный порт Эстерхольм + пиратская Чёрная Гавань + малые поселения, обломки, стоянки, неизведанные территории. Игрок: фракция → профессия → корабль → дом/предприятие → компания/гильдия → флот. История про власть, торговлю, политику, предательство и свободу. **Без магии, без суперсил, только люди.** Стиль: Stylized Realism + Medieval Maritime + Vintage Exploration.

Слоган (APPROVED): «Три горизонта — мир, который живёт».

## 2. Фракции (APPROVED)
### Арквейн / Arkwain — технологии и сила
Столица Аркенхольд 2.5×2 км. Остров 12×9 км (108 км²), высота 2800 м, население ~65 000. Технократическая монархия (монарх + Совет инженеров). Ресурс: эфирное топливо. Районы: королевская крепость, инженерный квартал, верфь, старый город, энергетический квартал, торговый порт, рабочие районы. Специализации: инженер, мушкетёр, дуэлянт, артиллерист. Дом-антагонист: Валькрофт.

### Вальмер / Valmere — вода и торговля
Столица Вальмара 3×2.5 км. Остров 24×18 км (432 км²), высота 2100 м, население ~90 000. Торговая олигархия (совет водных/торговых домов). Ресурс: аквакристалл (хранение/перевозка воды). Районы: советная площадь, большой рынок, водный квартал, купеческий район, порт, старый город, производственный район. Специализации: моряк, гарпунщик, абордажник, стрелок. Дом-антагонист: Сольвейн.

### Гринвальд / Greenwald — земля и урожай
Столица Гринхольм 3×2.5 км. Остров 25×19 км (475 км²), высота 1650 м, население ~80 000. Феодальная монархия (король + совет знати). Ресурс: небесное зерно. Районы: крепость, старый город, рынок, зернохранилища, мельничный квартал, ремесленный район, торговый порт, поместья. Специализации: следопыт, лучник, пехотинец, арбалетчик (см. противоречие C-03). Дом-антагонист: Рейвенхолл.

### Внефракционные (APPROVED)
- **Эстерхольм (нейтральный порт)**: 1.5×1 км, 1900 м, ~15 000. Точка встречи трёх сюжетов. Торговля без границ.
- **Чёрная Гавань (пираты)**: 0.8×0.6 км, 1700 м, ~8 000. Постройка из обломков/досок/парусов. Без единого правителя. Используют захваченные корабли.
- Малые поселения (APPROVED список): Бронзовый Холм, Фарнвик, Редстоун, Вестпорт, Зелёная Долина, Ривервуд, Солнечная Ферма + заброшки/обломки/стоянки/укрытия.

## 3. Герои (APPROVED)
- Эдриан / Элиана Вейл, 24, Арквейн, инженер. Отец пропал в госэкспедиции. Старт: малая верфь.
- Леонард / Леона Морвей, 26, Вальмер, торговец. Канон. написание: **Морвей / Morwey** (см. C-02). Семья потеряла груз аквакристаллов.
- Гаррет / Грейс Эшфорд (в атласах также Эшфорд), 23, Гринвальд, следопыт. Давление землевладельца, налоги.
Все трое независимо прибывают в Эстерхольм. Дальше — общий заговор трёх домов (Валькрофт + Сольвейн + Рейвенхолл): ломка компонентов, пропажа кристаллов и зерна. Раскрытие через расследования/документы/экспедиции. Без «древнего зла».

## 4. Корабли — ядро (APPROVED)
Три корпуса-конфигуратора (не классы): Лёгкий 18×6 м (разведка), Средний 32×10 м (универсал), Тяжёлый 48×15 м (груз/бой). Сборка из модулей: двигатель, топливо, корпус, палуба, паруса, вооружение, трюм, навигация, интерьер, флаги. Лимиты: масса/размер/мощность/вместимость/совместимость. Роли: капитан, штурман, инженер, канонир, гарпунщик, матрос. Интерьер обязателен (рубка, каюта капитана, машинное, трюм, кубрик, оружейная). Флот + NPC-капитаны + офлайн-симуляция сервером (без вечной физики каждого NPC).
> Дирижабли на артах — см. C-06: трактуются как художественная подача эфирной подъёмной силы, отдельный класс не вводится.

## 5. Персонажи/профессии (APPROVED)
Только люди. Внешность — пресеты разработчиков + покупная одежда/экипировка. Классов нет, есть обучение: инженерия, кузнечное дело, строительство, навигация, судовождение, торговля, земледелие, животноводство, стрельба, фехтование, ремонт, управление предприятиями. Мультипрофессии разрешены.

## 6. Экономика (APPROVED)
База статична (обычные товары всегда в NPC-магазинах), стратегия — лимитная (топливо/кристалл/зерно). Цепочки: древесина→доски; руда→металл→детали; зерно→мука→хлеб; волокно→ткань→одежда; эфир-сырьё→топливо. Покупка: дома, склады, мастерские, фермы, верфи. Совладение разрешено. Гильдии/компании/общие склады.

## 7. NPC / события / погода (APPROVED)
NPC: расписание+состояния, без тяжёлого ИИ; вне видимости — агрегация. События общие (одно пиратское нападение — одно на всех рядом, без копий на игрока) + личные квесты. День/ночь и погода (ясно/облачно/туман/шторм) синхронны, влияют на видимость/навигацию/посадку/износ.

## 8. Поражение (APPROVED)
Респаун в безопасной точке, навыки сохраняются, часть груза теряется; корабль: повреждение/потеря груза/захват (смена владельца)/уничтожение при крите. Краткий щит от повторной атаки.
