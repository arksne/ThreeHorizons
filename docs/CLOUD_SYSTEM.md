# CLOUD SYSTEM — облака Three Horizons

> Решение D-012. Статус: реализация готова (код + текстуры + физика), в игре не проверялось —
> Roblox Studio в этой сессии недоступен. Все проверки ниже офлайн (Luau CLI, PIL).

## 1. Почему отказались от меш-облаков

Эксперимент: облако из метаболов → voxel remesh → шум → decimate до 57 000 tri

Результат честно плохой: вблизи это «вата» или пластик. Причины не в количестве полигонов:

1. **Нет просвечивания.** Настоящее облако — плотная среда, а не поверхность. Свет входит в него
   на метры и рассеивается. Меш с шероховатой поверхностью этого не даёт: получается белый
   бугристый камень.
2. **Пропадает мягкость края.** У облака край растворяется в воздухе; у меша — резкая граница.
3. **Само-пересечения после шума и decimate** дают чёрные треугольники и «камуфляж» из UV-островов.

Платные паки на 57k tri выглядят реалистично не из-за полигонов, а потому что:
- у них запечены **normal + AO + opacity** карты и материал с subsurface/translucency;
- либо это **volumetric** (VDB/ray-marched) облака — у них нет меша вообще;
- рендер сделан в движке с правильным светом и постом.

Итог: **меш-облака не идут в игру**. Оставлены как эксперимент и как дальний силуэт для Steam.

## 2. Как сделано (три слоя)

| Слой | Что | Стоимость |
|---|---|---|
| Дальний план | Нативные объёмные `Lighting.Clouds` (Roblox) | 0 полигонов, 0 скриптов на кадр |
| Средний план / влёт | Слои альфа-клоньев `TH_TEX_CloudPuff_00…03` на скрещённых плоскостях | 9–12 тонких `Part` на облако |
| Внутри облака | `Atmosphere` (Density/Haze/Glare) + локальные клочья у игрока | по триггеру плотности |

Плюс **физика** (чистый Luau, без Roblox API): `TH_Shared/Sim/CloudField.lua` (создаётся в Ф12).

### 2.1 Нативный слой

`CloudSystem.applyWeather(state)` ставит `Lighting.Clouds` и `Lighting.Atmosphere` по пресетам:

| Погода | Cover | Density | Цвет | Atmosphere Density | Haze |
|---|---|---|---|---|---|
| clear | 0.18 | 0.35 | белый | 0.28 | 1.2 |
| overcast | 0.72 | 0.62 | серый | 0.42 | 2.4 |
| fog | 0.85 | 0.78 | серо-белый | 0.58 | 5.0 |
| storm | 0.95 | 0.92 | тёмно-серый | 0.50 | 3.2 |

Значения — в `TH_Shared/Config/Clouds.lua` (создаётся в Ф12), таблицы `NATIVE_BY_WEATHER` и `ATMOSPHERE_BY_WEATHER`.

### 2.2 Слой клоньев

+ радиальное затухание → мягкий рваный край, а не вырезанный кружок.

Каждое облако — `Model` из 9–12 плоскостей (`Part` + `SurfaceGui`/`ImageLabel`, лицо и тыл),
повёрнутых друг относительно друга. Это даёт объём без билбордов и без клиентского скрипта.

**Нужно после импорта:** загрузить 4 текстуры в Roblox и вписать id в `Clouds.TEXTURE_IDS`.

### 2.3 Физика (`CloudField.lua`)

- LCG-детерминизм: один seed → одно и то же небо (без `os.clock`, без math.random).
- Ветер зависит от высоты: `mul = 0.6 + alt*1.1`, поток слегка поворачивается с набором высоты.
- Порывистость: `gust` даёт синусоидальные колебания скорости.
- Мир заворачивается по прямоугольнику 12×12 км — облака не кончаются на краю.
- Плотность в точке — сумма эллипсоидных функций спада: `Σ(1-d²)² * density`, clamp 0..1.
- Видимость: `1 - 0.85 * density`.
- Турбулентность — вектор для качки корабля, ограничен по модулю.
- Погодные пресеты: `applyWeather(state)` (clear/overcast/fog/storm).

плотность в центре/на краю/снаружи, 10 минут симуляции без NaN.

### 2.4 API для других систем

```lua
local CloudSystem = require(SSS.TH_Server.World.CloudSystem)
CloudSystem.start(workspace)
CloudSystem.attachLoop()

CloudSystem.densityAt(pos)      -- 0..1
CloudSystem.visibilityAt(pos)   -- 1 = ясно, 0.15 = плотный туман
CloudSystem.turbulenceAt(pos)   -- Vector3 для качки
CloudSystem.applyWeather("storm")
CloudSystem.puffCount()
```

## 3. Производительность

- Нативные облака: 0 полигонов, 0 сетевых вызовов.
- Клочья: 9–12 `Part` на облако, только рядом с игроком; максимум `PUFF_MAX_ACTIVE = 6` облаков,
  живут `PUFF_LIFETIME_S = 6` с и плавно растворяются.
- Поле: шаг 4 Гц (`TICK_HZ`), 108 облаков в списке — это ~430 проверок плотности в секунду,
  только по запросу (корабль/камера) и при эмиссии рядом с игроками.

## 4. Что осталось

1. Загрузить 4 PNG в Roblox, заполнить `TEXTURE_IDS` (без этого клочья будут пустыми).
2. Включить `Lighting.Clouds` в месте и проверить `Cover/Density` в игре.
3. Связать `CloudSystem.applyWeather` с `WeatherService` (погодные циклы уже есть).
4. Для Steam: volumetric-облака средствами движка (UE/Unity/Godot), меш — только дальний силуэт.
