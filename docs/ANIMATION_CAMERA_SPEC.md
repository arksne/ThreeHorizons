# ANIMATION BIBLE (APPROVED v0.1)
- Персонажи: ходьба 1.6 м/с, бег 4.5 м/с; работа (молот/пила/пахота) loop 2 с; экипаж: штурвал-hold, канонир-зарядка 3 с.
- Без акробатики и магии; всё сдержанное, «люди, а не герои боевика».
- Механизмы: мельницы 6 об/мин, краны-верфи — медленно; двигатель — вибрация 55 Гц визуалом.
- UI: тосты 200 мс fade, окна — без bounce.
- Именование: `TH_AN_{кто}_{действие}_v1`; реестр — ASSET_REGISTRY §anim.

# CAMERA DESIGN SPEC (APPROVED v0.1)
- Исследование: 3-е лицо 8–12 м, FOV 60. Город: 5–8 м, FOV 55. Корабль: орбита 15–30 м + вид от штурвала (FOV 65). Интерьер: близкое 3-е / 1-е, клип через стены запрещён (collision).
- Катсцены: скип всегда, ≤5 с блокировки управления. Чувствительность и инверсия — в настройках, доступность: FOV-слайдер, тряска выкл.
