# AUDIO DESIGN BIBLE (APPROVED v0.1 — направление, ассеты позже лицензированные)
- Общая: акустические струнные + духовые, без электроники; темп 70–95 BPM; морская рабочим-песенная основа.
- Арквейн: молот/наковальня, гул механизмов, низкий брасс; Вальмер: вода/канаты/чайки, мандолина; Гринвальд: ветер/мельницы/птицы, флейта.
- Корабли: скрип такелажа, гул эфирного двигателя (лоу-пасс шум + тон 55 Гц), ветер по парусам.
- Погода: туман — приглушение ВЧ; шторм — порывы + гром через 1–3 с.
- UI: пергамент-шелест, латунь-клик; уровни −12 dB FS макс. Только licensed/original audio.

# UX DESIGN SPEC (APPROVED v0.1)
Единые глаголы: E — говорить/взять/открыть; F — якорь/швартовка; M — карта; Tab — инвентарь; H — помощь. Подсказка всегда одинаковым тостом внизу. Торговля/склад/верфь — один шаблон окна (список слева, детали справа, кнопка действия внизу). Тач: те же глаголы крупными кнопками. Дальтонизм: ресурсы дублируются иконкой, не только цветом.

# OPTIMIZATION PLAN (APPROVED v0.1)
Бюджеты: near-parts ≤ 8000, draw calls — минимизировать (объединение статики чанка в 1–3 MeshPart), NPC активных ≤ 25/шард рядом, корабли с физикой ≤ 12 рядом, Remote ≤ 60/с/игрок, свет: 1 Directional + Atmosphere + локальные PointLight только в интерьерах рядом.
Приёмы: StreamingEnabled (Low 500 / Med 900 / High 1400 st), LOD (L0 near, L1 >300 st — без декора, L2 импостор), CanCollide/CanQuery выкл вдали, кэш расписаний NPC, батчинг тиков погоды/событий, сжатие сохранений (короткие ключи).
Профили: Auto (FPS<30 → шаг вниз), ручной Low/Med/High в настройках.
