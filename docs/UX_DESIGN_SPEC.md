# UX DESIGN SPEC (APPROVED v0.1)
> Единые правила взаимодействия. Источник: Master Prompt §17 + атлас UI (ref05/ref07: пергамент, латунь, круглая миникарта).

## Глаголы (везде одинаковые)
| Действие | ПК | Тач | Геймпад-план |
|---|---|---|---|
| Говорить/взять/открыть | E | кнопка ✋ 64pt | X |
| Якорь/швартовка | F | кнопка ⚓ | Y |
| Карта | M | кнопка 🗺 | View |
| Инвентарь | Tab / I | кнопка 🎒 | LB |
| Помощь | H | кнопка ? | — |

Тост-подсказка всегда внизу по центру, один стиль: `TH_UI_Hint`.

## Окна (один шаблон)
Список слева → детали справа → действие внизу. Применяется к: торговля, склад, верфь, флот, гильдия, предприятия, карта, персонаж, профессии, задания, настройки (11 окон из §17).

## Стиль
Пергамент PARCHMENT #E8DCC0, рамки BRASS 2px, радиус 4px, заголовок serif, тело sans 14–16px. Ресурсы дублируются иконкой (дальтонизм). Мобильные кнопки ≥44pt.

## Корабль
Штурвал — drag/джойстик; газ — слайдер; высота — +/-; торможение — hold; якорь — F. Все манёвры подтверждает сервер.
