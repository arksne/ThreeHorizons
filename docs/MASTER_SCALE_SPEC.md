# MASTER SCALE SPEC (APPROVED v0.1)
> Единственная система масштабов. Всё в метрах в лоре; в Roblox — studs. Случайных масштабов нет.

## 1. Базовая единица
- **1 метр = 3 studs** (канон Roblox: персонаж ~5 studs ≈ 1.65–1.8 м).
- Оси: +X восток, +Z юг, +Y вверх. Юнит rot — градусы, фасад — на −Z? Нет: **фасад здания всегда на +Z локального space** (дверь/вывеска), точка опоры (pivot) — центр основания (y=0 у земли/палубы). Все Blender-экспорты с pivot в основании, forward −Y? Нет — Blender forward −Y при экспорте FBX → Roblox −Z: правило в `blender/export_preset.md`.
- Именование частей: `TH_{faction}_{category}_{name}_{part}` напр. `TH_ARK_House_Wall01`.

## 2. Персонаж и эргономика
- Рост: 1.7 м (5.1 studs). Ширина плеч 0.5 м. Дверь: 1.0×2.1 м (3×6.3 st). Коридор ≥1.2 м. Потолок жилого: 2.7 м; трюм/машинное: 3.2 м. Мебель: стол 0.75 м высота, стул 0.45, кровать 2.0×0.9, шкаф 0.6 глуб.
- Лестницы: ступень 0.25 глуб / 0.18 выс. Пандус ≤ 20°.

## 3. Город
- Улица второстепенная 4 м, главная 8 м, площадь мин 20×20 м. Причал под средний корпус: 40×14 м. Расстояние между домами ≥ 3 м (пожарный разрыв по лору).

## 4. Корабли (лор → Roblox)
- Лёгкий 18×6 м = 54×18 st; Средний 32×10 = 96×30 st; Тяжёлый 48×15 = 144×45 st. Высота борта 2.5/3.5/4.5 м. Мачта лёгкого ≤ 14 м.
- Коллизии: корпус — 1 CanCollide-бокс + палуба; такелаж/декор — CanCollide=false, CanQuery — по необходимости.

## 5. Мир (лор vs игра)
- Лор-размеры островов — §2 Bible. Игровая шкала: **1:20** (PROPOSED→APPROVED здесь как v0.1): Арквейн 600×450 м игрового, Вальмер 1200×900, Гринвальд 1250×950. Высоты сохраняем как геймплейные дельты: 2800/2100/1650/1900/1700 → делим на 20 по вертикали тоже? Нет: вертикаль делим на 10 для читаемости полёта (см. WORLD_MASTER_MAP).
- Дальность стриминга: город 800 st, остров 4000 st, межостровье — импостор неба.
