## [2026-11-02] v1.5.0 — Облака: система, физика, отказ от меш-облаков (D-012)
- **Решение D-012**: облака в игре — не меши. Эксперимент с 57k-tri облаком (метаболы → voxel remesh → шум → decimate) показал главное: полигонами не получить просвечивания и мягкого края, вблизи это «вата». Меш оставлен только как дальний силуэт для Steam.
- **Физика облачного поля** TH_Shared/Sim/CloudField.lua (чистый Luau, без Roblox API): детерминированный LCG, высотный ветер (сильнее и закручен выше), порывы, заворот мира 12×12 км, плотность через сумму эллипсоидных спадов, видимость, турбулентность для качки корабля, пресеты погоды. Офлайн-тесты: **15/15** (	ools/build_cloud_test.py).
- **Серверный слой** TH_Server/World/CloudSystem.lua: нативные объёмные Lighting.Clouds + Atmosphere по погоде, слои альфа-клоньев на скрещённых плоскостях, авто-эмиссия клочьев вокруг игрока при плотности > 0.25, плавное растворение, лимит 6 активных облаков.
- **Текстуры клоньев** ART_ASSETS/textures/clouds/TH_TEX_CloudPuff_00…03.png (512², RGBA): фрактальный шум + кластер клочьев + радиальное затухание → мягкий рваный край. Генератор: 	ools/make_cloud_puff_textures.py.
- **Документ** docs/CLOUD_SYSTEM.md: почему меш-облака не работают, три слоя, таблицы пресетов погоды, API, производительность, что осталось (загрузить текстуры, связать с WeatherService).
- Компиляция Luau: Clouds.lua, CloudSystem.lua, CloudField.lua, MeshAssets.lua — OK.

## [2026-11-02] v1.4.0 — Текстуры на hero-моделях, новые типы зданий, сцены столиц
- **PBR-текстуры применены в Blender-пайплайне**: `make_textured_material()` цепляет `ART_ASSETS/textures/TH_TEX_<материал>_{a,n,r}.png` через Mapping (тайлинг 1.5–3.0) в Base Color / Roughness / Normal. 66 текстур теперь видны на моделях, а не лежат мёртвым грузом.
- **Рендер прямо из сборки**: `hero_export.py --render` рендерит превью с текстурами до декомпозиции (раньше FBX реимпортировался без материалов и текстуры терялись).
- **Новые типы ассетов** (+8): усадьба (`manor`, 10–11.7k tri, 3 этажа + угловая башня + портик с колоннами), склад (`warehouse`, 2.3k tri, ворота, погрузочная платформа, груз), городская стена (`wall_segment`, зубцы + ходовая площадка), ворота с аркой и двумя башнями (`wall_gate`), причал (`pier`).
- **Сцены столиц** (`blender/scene_street.py`): из готовых FBX собирается улица квартала — 7 зданий + стена/причал + мостовая + деревья (Гринвальд) + море облаков; 2 кадра на фракцию (общий вид и «от глаз» на 1.7 м). 6 рендеров 1600×900.
- **Мост в Roblox**: `MeshAssets.nameForKind()` + `ENV_NAMES` (стена/ворота/причал), `MeshBuilding` берёт имена через него; оба модуля проходят `luau-compile`.
- Исправлено: кэш материалов переживал сброс сцены, рендер писался в корень воркспейса, ставни были слишком крупными («синяя клетка» Вальмера), деревья были конусами.
