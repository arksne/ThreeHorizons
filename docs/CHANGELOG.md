    Гринвальд 625×475 м, Эстерхольм 225×150 м, Чёрная Гавань 120×90 м).
- Раскладка островов по лор-координатам (WORLD_MASTER_MAP): Арквейн (−1215,−1755),
  Вальмер (1215,−135), Гринвальд (0,1755), Эстерхольм (67,0), Чёрная Гавань (−810,1080) стадов.

  `TH_Cloud_Big_01`): тайлы поверхности + кучевые клубы + крупные массивы, единый белый
