# TRADE_ROUTES.md

- Arkvein ↔ Black Harbor: корабли/механизмы в обмен на товары всех фракций.
- Valmer ↔ Black Harbor: вода/окраска очистки в питьё/услуги.
- Grinwald ↔ Black Harbor: продовольствие.
- Esterholm ↔ Black Harbor: исследовательские грузы (из руин).
- Pirate Base: рейды на Arkvein↔Black Harbor.

Требования: маршруты без пересечений по берегам, эскорт-точки, промежуточные склады.
