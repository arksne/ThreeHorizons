# ARCHITECTURE_GUIDE.md

1. Стилизованно-реалистичный старинный островной мир над облачным океаном.
2. Идентичность фракций: разные палитры/материалы/декор из WORLD_PALETTE.md.
3. Здания собираются из модульных наборов: стены/крыши/фундаменты/двери/окна/балконы/лестницы/перила/декор.
4. Размеры из BUILDING_CATALOG.md; люди 1.7 м, двери 2.2 м, потолки 2.8–3.2 м.
5. Материалы естественные; прежние решения Three Horizons не заменять.
6. Порты детальные; фермы живые; промзоны с инфраструктурой; острова с выразительными силуэтами.
7. Единый реестр: WORLD_COORDINATES.csv — все новые объекты привязаны к нему и к общей географии.
