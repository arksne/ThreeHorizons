# Three Horizons — база 0.1 (только лор)

В проекте оставлены только данные лора. Все наработки — скрипты, генераторы, арт-пайплайны,
экспорт, референс-атласы, игровые таблицы и визуальный роадмап — вынесены в
`../_TRASH_2026-11-10/ThreeHorizons/` (восстанавливаются обратным переносом).

## Что есть

- `docs/` — канон проекта: библия, World Bible, визуальная и звуковая библии, спецификации,
  решения, статус, чек-листы (40 `.md` + данные).
- `docs/THREE_HORIZONS_PROJECT_BIBLE.md` — единственный источник истины по лору и правилам.
- `.git/` — история репозитория сохранена (удалённые файлы при необходимости достаются из неё).

## Правило нового старта

Всё, что не является лором, создаётся заново с нуля и нумеруется с **v0.1**. Старые реализации
не восстанавливаем и не переносим — только сверяемся с каноном в `docs/`.

## Что дальше

Работаем по **[ROADMAP_0.1.md](ROADMAP_0.1.md)**: 12 фаз, 147 шагов, у каждого — что сделать, чем,
что должно получиться и критерий «готово». Детали фаз — в `docs/roadmap/phase-00…phase-11`.

Визуальная версия для правки — **`ROADMAP_0.1.canvas`** (индекс: 12 фаз крупными карточками) и
**`docs/roadmap/canvas/phase-XX.canvas`** (канвас на каждую фазу: шаги крупно + Definition of Done,
риски, «чего не делаем»; читается при 100 % без зума). Есть и автономный **`ROADMAP_0.1.html`**
(двойной клик → браузер, без Obsidian). Пересборка: `python -X utf8 tools/make_roadmap_canvas.py`,
`python -X utf8 tools/make_roadmap_html.py`.

Порядок: Ф0 (база) → Ф1 (канон в данные) → Ф2 (масштаб/карта) → параллельно Ф3–Ф4 (арт) и Ф5 (код)
→ Ф6 (мир) → Ф7 (облака) → Ф8 (корабль) → Ф9 (механики) → Ф10 (UI/звук) → Ф11 (QA/альфа).

Правило: шаг не закрыт, пока не выполнен его критерий «готово»; отступление от канона — только через
`docs/DECISIONS.md`.
