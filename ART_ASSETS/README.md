# ART_ASSETS — исходники арта и превью

| Папка | Что лежит |
|---|---|
| `models/` | исходники и рабочие файлы моделей (Blender .blend — **не коммитим**) |
| `textures/` | PBR-текстуры и манифест (PNG в git не тянем, только `manifest.json`) |
| `previews/` | рендеры/скриншоты для глазной проверки (3/4, фасад, деталь) |
| `roadmap/` | превью канваса роадмапа (генерируется скриптом) |

## Правила

- Имя ассета: `TH_<FACTION>_<TYPE>_<VAR>` (+ `_L1`, `_L2` для LOD) — см. `docs/NAMING.md`.
- Пивот — основание по центру, фасад вперёд, единицы — метры; масштаб применяет импортёр.
- Бюджеты: hero ≤ 12 000 tri, MeshPart ≤ 9 500, LOD L1 ≤ 35 %, L2 ≤ 8 %.
- Палитра — только токены из `docs/DESIGN_TOKENS.md`.
- Любой ассет проходит гейт A-1 и попадает в `docs/ASSET_REGISTRY.md`.

Пайплайн: `docs/ART_PIPELINE_BLENDER_KIT.md`, `docs/TEXTURE_PIPELINE.md`.
